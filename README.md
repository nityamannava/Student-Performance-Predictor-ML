# Student-Performance-Predictor-ML
Student Performance Predictor &amp; Tracker using Machine Learning
A web application to predict and track student academic performance using Machine Learning.
Tech Stack

Python, Django
Machine Learning: scikit-learn, XGBoost
Database: SQLite3

Roles

Admin – Manage students and faculty
Faculty – Add marks, attendance, and assignments
Student – View marks, progress report, and ML predictions
